# Atividade - Eventos JavaScript - Manipulando o DOM

1. [✔] Crie uma página com 4 botões (Azul, Verde, Vermelho, Branco) que alterem a cor de fundo da página quando clicados.

2. [✔] Crie um contador que inicie em 0, e através de botões "+" e "-" aumente e diminua o valor exibido em um campo da tela.

3. [✔] Para o exercício anterior, caso o número incrementado seja maior que 5, o resultado deve ser exibido em cor vermelha.

4. [✔] Crie um parágrafo com texto e dois botões: "Mostrar" e "Esconder" que controlem a visibilidade do texto.

5. [] Crie um campo de input de texto e utilize o evento "onkeydown" para exibir uma mensagem de alerta contendo o texto "Você pressionou uma tecla!" sempre que uma tecla for pressionada nesse campo.

6. [] Modifique a atividade anterior para que, ao invés de uma mensagem genérica, a mensagem de alerta exiba qual tecla foi pressionada. [] Utilize a propriedade event.key para isso

7. [] Utilize um evento de teclado que faça um espelhamento em tempo real do que o usuário digita em um campo de formulário, de modo que a digitação seja exibida em um parágrafo abaixo do campo.

8. [] Utilize um evento de janela que exibe uma mensagem no console toda vez que a janela for redimensionada.

9. [] Crie uma página com uma div de altura suficiente para gerar uma barra de rolagem e adicione o evento "onscroll”. [] Toda vez que a barra de rolagem for movida, exiba a mensagem "Barra de rolagem movida!" no console do navegador.

10. [] Crie um campo de texto e aplique uma função com evento de formulário para que, quando o campo receber o foco do cursor (evento onfocus), mude sua cor de fundo. [] Quando perder o foco (evento onblur), retorne a cor de fundo para branco.

11. [] Crie uma página com um campo select contendo as opções "Português", "Inglês" e "Alemão". Utilize o evento "onchange" para que, quando o usuário selecionar um idioma, seja exibida uma saudação correspondente em um parágrafo da página: "Seja bem vindo ao curso de programação web!" para Português, "Welcome to the web programming course" para Inglês e "Bienvenido al curso de programación web!" para espanhol.
